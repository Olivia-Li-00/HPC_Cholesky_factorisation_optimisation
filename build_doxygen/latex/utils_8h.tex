\subsection{Detailed Description}
\+: Shared utility for correlation matrix generation and validation 

\mbox{\hyperlink{utils_8h}{utils.\+h}} Provides helper functions commonly used across the project for\+:
\begin{DoxyEnumerate}
\item Computing pairwise correlation values
\item Populating symmetric positive-\/definite correlation matrices
\item Computing log-\/determinants from Cholesky-\/factorised matrices as a correctness check (using Equation 4 from the coursework)
\end{DoxyEnumerate}

All functions are defined as described from the coursework.

\+: Compute the log-\/determinant of a matrix from its Cholesky factor 

Given a lower-\/triangular Cholesky factor L (where C = L $\ast$ L$^\wedge$T), computes log(det(\+C)) using Equation 4 from the coursework.
