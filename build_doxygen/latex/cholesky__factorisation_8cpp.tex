\subsection{Detailed Description}
\+: Cache-\/blocked, multi-\/threads optimised Cholesky factorisation (v1.\+2) 

\mbox{\hyperlink{cholesky__factorisation_8cpp}{cholesky\+\_\+factorisation.\+cpp}} This file builds on v1.\+1 by introducing cache blocking via a three-\/step blocked outer loop stepping by block size B along the diagonal\+:
\begin{DoxyItemize}
\item Step 1\+: Factorise the B x B diagonal block (upper triangle only)
\item Step 2\+: Update the panel to the right of the diagonal block with static scheduling due to uniform workload per column
\item Step 3\+: Trailing submatrix update, with runtime scheduling via O\+M\+P\+\_\+\+S\+C\+H\+E\+D\+U\+LE to handle flexibility to test for different schedulers due to varied workload
\end{DoxyItemize}

Optimisations carried forward from v1.\+1\+:
\begin{DoxyItemize}
\item Open\+MP multi-\/thread parallelisation Optimisations carried forward from v0.\+4\+:
\item S\+I\+MD pragmas on inner loops for vectorisation
\item \+\_\+\+\_\+builtin\+\_\+expect on error path for branch prediction Optimisations carried forward from v0.\+3\+:
\item Symmetry exploitation\+: only upper triangle updated, with final copy pass Optimisations carried forward from v0.\+2\+:
\item Multiplication by reciprocal instead of division Optimisations carried forward from v0.\+1\+:
\item Reordered submatrix update loops to avoid strided memory access
\item Hoisted j-\/independent elements out of the j-\/inner loop
\end{DoxyItemize}

Algorithm complexity remains O(n$^\wedge$3).

\begin{DoxyItemize}
\item Introduces cache blocking\+: the outer loop iterates by block size B, splitting each block step into three processes (see file header).

\begin{DoxyEnumerate}
\item Mathematical Foundation\+: Given any symmetric, positive-\/definite matrix C, one could factorise such matrix into a lower-\/upper form\+: C = L L$^\wedge$T where L is a lower-\/triangular matrix and L$^\wedge$T is its symmetric transpose
\item Algorithm Description\+: This function factorises the C matrix by processing one B x B diagonal block at a time. Step 1 factorises the block, Step 2 updates the panel to its right, and Step 3 updates the trailing submatrix using all B panel rows. After the blocked loop, the upper triangle is copied to the lower triangle.
\item Algorithm Complexity\+: O(n$^\wedge$3) due to the triple nested loops; improves cache utilisation and runtime.
\end{DoxyEnumerate}
