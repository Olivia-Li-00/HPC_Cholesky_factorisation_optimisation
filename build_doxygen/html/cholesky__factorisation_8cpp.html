Detailed Description

: Cache-blocked, multi-threads optimised Cholesky factorisation (v1.2)

cholesky_factorisation.cpp This file builds on v1.1 by introducing cache blocking via a three-step blocked outer loop stepping by block size B along the diagonal:

  • Step 1: Factorise the B x B diagonal block (upper triangle only)
  • Step 2: Update the panel to the right of the diagonal block with static scheduling due to uniform workload per column
  • Step 3: Trailing submatrix update, with runtime scheduling via OMP_SCHEDULE to handle flexibility to test for different schedulers due to varied workload

Optimisations carried forward from v1.1:

  • OpenMP multi-thread parallelisation Optimisations carried forward from v0.4:
  • SIMD pragmas on inner loops for vectorisation
  • __builtin_expect on error path for branch prediction Optimisations carried forward from v0.3:
  • Symmetry exploitation: only upper triangle updated, with final copy pass Optimisations carried forward from v0.2:
  • Multiplication by reciprocal instead of division Optimisations carried forward from v0.1:
  • Reordered submatrix update loops to avoid strided memory access
  • Hoisted j-independent elements out of the j-inner loop

Algorithm complexity remains O(n^3).

Cholesky Factorisation Algorithm 

     ***** Improvement compared to v1.1 *****
  • Introduces cache blocking: the outer loop iterates by block size B, splitting each block step into three processes (see file header).
  1. Mathematical Foundation: Given any symmetric, positive-definite matrix C, one could factorise such matrix into a lower-upper form: C = L L^T where L is a lower-triangular matrix and L^T is its symmetric transpose
  2. Algorithm Description: This function factorises the C matrix by processing one B x B diagonal block at a time. Step 1 factorises the block, Step 2 updates the panel to its right, and Step 3 updates the trailing submatrix using all B panel rows. After the blocked loop, the upper triangle is copied to the lower triangle.
  3. Algorithm Complexity: O(n^3) due to the triple nested loops; improves cache utilisation and runtime.
Parameters
cPointer to a symmetric positive-definite matrix in row-major order (n x n) stored as a 1D array. This is modified in-place to store the lower triangular factor L and its transpose L^T
nDimension of the square matrix (must satisfy 0 < n <= MAX_N)
Returns
: On success: Wall-clock time (seconds) taken for factorisation On failure: -1.0 with appropriate error message printed to stderr
