Detailed Description

: Shared utility for correlation matrix generation and validation

utils.h Provides helper functions commonly used across the project for:

  1. Computing pairwise correlation values
  2. Populating symmetric positive-definite correlation matrices
  3. Computing log-determinants from Cholesky-factorised matrices as a correctness check (using Equation 4 from the coursework)

All functions are defined as described from the coursework.

: Compute the log-determinant of a matrix from its Cholesky factor

Given a lower-triangular Cholesky factor L (where C = L * L^T), computes log(det(C)) using Equation 4 from the coursework.

Intended to be called after cholesky_factorisation() has been applied to the input matrix, and used to compare against the original matrix as a correctness check.
